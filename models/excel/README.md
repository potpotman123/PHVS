# PHVS workbook (Crimson Capital)

`PHVS_Crimson_Capital_Model.xlsx` is the live Excel model for the Point72 Academy case. It is generated by `build_model.py` from the canonical engine inputs in `models/finalized/` and reconciled against the Python engine by `reconcile.py` and `check_cases.sh`.

## Build and verify

```sh
python3 models/excel/build_model.py          # writes the workbook and rowmap.json
python3 <xlsx-skill>/recalc.py models/excel/PHVS_Crimson_Capital_Model.xlsx 900   # LibreOffice recalculation
python3 models/excel/reconcile.py working    # every monthly series and branch price against working_monthly.json
./models/excel/check_cases.sh                # same for Working, Cautious and Upside in disposable copies
```

Requires Python 3.9+ with openpyxl (the agents' data tables are read from two JSON files compiled from the research archive; see `altdata` under the scratch folder recorded in the build script, or regenerate from the repo files listed on each Alt Data tab).

## What recalculates and what is saved

Live formulas: Inputs (case selector, overrides), Adoption Build, XR Engine, IR Engine, Revenue, Fin Monthly (four clinical branches), Valuation, Annual, Quarterly, Quantity & Price, Checks, LOE, Calendar. Changing any input recalculates patients, revenue, cash, funding and value.

Saved engine results, labelled as such: Sensitivities (one-variable ranges, structural stresses, cases), Street Bridge value waterfall (four engine runs, one with the redosing haircut relaxed for sizing only), Monte Carlo (4,096-draw run on commit e7594c4, seed 7202609). The Monte Carlo tab flags when live inputs no longer match the simulated baseline. Refresh the simulation with `models/monte_carlo/run.py`, then rebuild.

## Reconciliation, 10 October 2026

Recalculated in LibreOffice 25.x (soffice at /opt/homebrew/bin) with 298,145 formulas and zero errors. Working, Cautious and Upside cases reproduce the engine's monthly patient-years, active members, doses, units, revenue, costs, taxes, cash, shares, equity and liquidation distributions in all four clinical branches within 1e-6, and all eight branch prices within 1e-6 per share. Control totals on the Checks tab: value today $25.8256, 12-month value $28.3116, both-approved target $31.4954, peak revenue $1,551.2m in 2038.

Method: first-year cohorts collapse exactly into a 12-month SUMPRODUCT because first-year hazard is constant; mature cohorts roll forward as one stock; access delay and retry cooldown are fixed-lag columns. XR population flows do not depend on IR; IR flows do not depend on XR except through the dose-budget overlap, so one XR ledger, one IR ledger and two IR dose sets (with and without XR) serve all four branches.

Not verified: native Microsoft Excel recalculation (no Excel on the build machine). Formulas use only SUMIFS, AVERAGEIFS, SUMPRODUCT, INDEX, MATCH, EOMONTH, MIN, MAX, LN and defined names. Excel data tables are not used, so sensitivity tables are engine-computed values rather than live two-way tables.

## Limitations carried from the engine

Comparator list prices with assumed net fractions; claims and survey benchmarks transferred as switching, preference and dose inputs; 60% mature oral share and the 1.17/1.38 redosing haircut fixed by analyst choice; funding plan is a requirement, not committed capital; economic cash-compensation statements rather than IFRS forecasts. The Inputs tab states the source and reasoning for each assumption.
